## Publicar en GitHub Wiki

GitHub crea una wiki independiente del árbol principal. Para publicarla:

1. Crea la wiki del repositorio en GitHub.
2. Copia el contenido de este directorio a la wiki.
3. Mantén `Home.md` como página principal y `_Sidebar.md` como navegación.
4. Revisa los enlaces relativos si tu visor no resuelve la extensión `.md`.

Las páginas usan enlaces relativos con `.md` para que funcionen al abrir la
wiki desde el repositorio. GitHub Wiki normalmente resuelve los nombres de
página; si algún enlace no funciona en la wiki publicada, elimina el sufijo
`.md` en ese enlace.
